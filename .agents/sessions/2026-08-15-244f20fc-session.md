## What We Are Building

A unified, authoritative tooling harness, capability discovery engine, and developer prompt cookbook named **`agy-tool`** (`.agents/skills/agy-tool/`) adhering to the **`agentskills.io/v1.0`** and **7-Pillars AI-Friendly Docs** standards.

The skill unifies the entire Antigravity tooling ecosystem into 4 distinct, deterministic tiers:
1. **Tier 1 (Native Core Tools)**: All 20 built-in `default_api` harness tools (`view_file`, `replace_file_content`, `run_command`, `invoke_subagent`, `send_message`, `call_mcp_tool`, etc.).
2. **Tier 2 (MCP Federated Servers)**: 17 local and global MCP servers (`context7`, `graphify`, `mcp-server-neon`, `Sanity`, `cloudflare-bindings`, `cloudflare-observability`, `playwright`, `browser-use`, `firecrawl`, `github`, `token-optimizer`, etc.).
3. **Tier 3 (Antigravity CLI & TUI)**: `agy` CLI flags (`-p`, `--resume`, `--sandbox`), session controls, and TUI slash commands (`/compact`, `/stats`, `/model`, `/checkpoint`, `/export`, `/clear`).
4. **Tier 4 (Repository SDD Workflows & Custom Tools)**: OpenSpec SDD pipelines (`/opsx-propose`, `/opsx-apply`, `/opsx-verify`, `/opsx-archive`), 7-Pillars AI-Docs suite (`validate-ai-docs.cjs`, etc.), and harness diagnostics.

Additionally, four advanced features were engineered into a zero-dependency CLI discovery runner (`scripts/help.js`):
- `--inspect <tool_name>`: Parameter schema inspector with typed table and valid JSON payload.
- `--recipe <intent>` / `--prompt <tool>`: Copy-pasteable prompt formulas with dynamic placeholder tokens.
- `--doctor` / `--health`: Sub-300ms non-blocking system diagnostics and masked environment secrets probe.
- `--export-md [path]`: Standalone 7-Pillars cheatsheet generator (`docs/CHEATSHEET_TOOLS.md`).

## What Did NOT Work (and why)

- **Initial `define_subagent` Call Signature** — failed because: Tool schema required exact lowercase parameter names (`system_prompt`, `name`, `description`, `enable_write_tools`, `enable_mcp_tools`). Resolved immediately by supplying exact casing.
- **Dynamic Regex Highlighting Vulnerability (ReDoS Risk)** — flagged by Adversarial Red Teamer: Dynamic `new RegExp()` on user search input could cause catastrophic backtracking. Resolved by replacing with zero-backtracking literal substring scanner (`safeHighlightQuery`).
- **Windows Path Backslash Incompatibility** — flagged during QA: Windows `\` delimiters could break POSIX markdown links and tool contracts. Resolved by implementing `toPosixPath` across all output paths.
- **Doctor Sync Process Deadlock Risk** — flagged during QA: `execSync` commands probing CLI tools could hang on interactive TTY prompts. Resolved by adding non-interactive environment flags, 200ms strict timeouts, and ignoring stdin.

## Decisions Made

- **Standardization on `agentskills.io/v1.0`** — reason: Ensures compatibility across Antigravity IDE, Antigravity 2.0 desktop, CLI (`agy`), and Gemini agent platforms.
- **Strict Zero External Dependencies** — reason: Prevents `node_modules` rot, ensures instant execution (<40ms cold start), and allows running anywhere Node.js 18+ is available.
- **Anthropic GAN Harness with Hard Max 3 Iterations** — reason: Guarantees objective, adversarial verification without endless repair loops (converged on Iteration 1).
- **Sub-300ms Doctor Budget** — reason: Diagnostics must run instantaneously during agent pre-flight checks without stalling workflows.
