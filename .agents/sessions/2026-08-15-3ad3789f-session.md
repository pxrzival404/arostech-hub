## What Did NOT Work (and why)

- **Purely Stripping `allowed-tools: Bash(openspec:*)`** — failed because: while eliminating non-standard whitelists in general skills is proper, in OpenSpec skills `allowed-tools: Bash(openspec:*)` is the upstream OpenSpec 1.8.0 CLI adapter pattern for pre-approving `openspec` node commands. Stripping it violated upstream OpenSpec CLI auto-approval generator standards. Solution: Restored and harmonized with dual `tools: [...]` + `allowed-tools: Bash(openspec:*)`.
- **Calling `graphify:query_graph` with `query:` argument** — failed because: the MCP tool schema expects `question:` instead of `query:`. Solution: Updated call parameter to `{ question: "..." }`.
